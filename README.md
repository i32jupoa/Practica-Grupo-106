"Practica del grupo 106" 
Esta practica consiste en un programa para la gestion del programa SICUE. Consiste en un menu con diferentes opciones: Inscribir alumnos y ver inscripciones, 
agregar planes de convalidacion y mostrarlos, ejecutar pruebas para ver el correcto funcionamiento del programa (solo desarrolladores y administradores) y la ultima opcion
para salir del menu.
